# User Journey

**Project:** JOTI – Kundalini ABC Yoga

**Status:** Draft v1

---

# Purpose

This document describes how learners experience JOTI throughout their learning journey.

Unlike the Website Sitemap, which defines the structure of the website, this document focuses on the learner's perspective.

It answers questions such as:

- How does a new learner begin?
- How does a returning learner continue practicing?
- When should advanced features become available?
- How does the product support long-term practice?

The goal is to ensure every feature contributes to a smooth and meaningful learning experience.

---

# Learning Philosophy

JOTI is designed around a simple belief:

Learning Kundalini Yoga is a journey, not a collection of videos.

The product should guide learners step by step, helping them build confidence, consistency, and long-term practice habits.

---

# Journey Overview

Every learner follows the same overall path:

Discover JOTI

↓

Build Foundations

↓

Start Practicing

↓

Develop Consistency

↓

Personalize Practice

↓

Continue Lifelong Learning

Each stage introduces only the tools and knowledge needed at that moment.

---

# Stage 1 — Discover JOTI

## Goal

Help visitors understand what JOTI is and encourage them to begin.

Typical questions:

- What is Kundalini Yoga?
- Is this suitable for beginners?
- Who is the teacher?
- Where should I start?

Primary pages:

- Home
- About
- External Links

Primary action:

Enter Courses

---

# Stage 2 — Foundation

## Goal

Build essential knowledge before regular practice.

Learners should first understand:

- Breathing
- Body Locks
- Tune In
- Basic concepts

At this stage, learners are not expected to create their own practice.

Primary action:

Complete Foundation lessons.

Next step:

Start Practice

---

# Stage 3 — Start Practice

## Goal

Help learners experience complete, guided practices.

This is the main destination for returning learners.

The page should immediately encourage learners to begin today's practice.

Examples of sections:

- Recommended
- Beginner
- Energy
- Relaxation
- Breath & Meditation

These sections organize Practices visually rather than creating additional navigation layers.

Primary action:

Choose a Practice.

---

# Stage 4 — Build Consistency

## Goal

Encourage regular practice.

Over time, learners should feel comfortable returning to JOTI as part of their daily routine.

Future features may include:

- Practice Calendar
- Practice History
- Streaks
- Challenges

The emphasis is on consistency rather than completion.

---

# Stage 5 — Personalize Practice

## Goal

Allow experienced learners to create practices that match their own needs.

Most learners will reach this stage naturally after becoming familiar with official Practices.

Primary action:

Build Your Own Practice

↓

Module Library

The Module Library remains an advanced tool.

It is intentionally hidden until learners choose to customize their practice.

---

# Stage 6 — Lifelong Learning

## Goal

Support learners over many years.

The platform should continue offering:

- New Practices
- New Foundations
- AI Guidance
- Community
- Personal Growth

Learning should remain open-ended rather than ending after completing a course.

# Progressive Disclosure

New learners should see:

- Foundation
- Start Practice

Returning learners gradually discover:

- More Practice categories
- Member content

Advanced learners eventually discover:

- Build Your Own Practice
- Module Library

Complexity should increase only as the learner becomes ready.

---

# Success Indicators

The product succeeds when learners:

- Know where to begin.
- Feel encouraged to practice.
- Return regularly.
- Gradually explore more features.
- Spend more time practicing than navigating.
