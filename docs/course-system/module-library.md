# Module Library

## Purpose

Module 是組成 Practice 的基本單位（Building Block）。

每一堂 Practice 都是由多個 Module 所組成。

每個 Module 都有明確的目的、類型與規則，由官方建立，也可作為 AI 組課與學員自由組課的基礎元件。

一個 Module 對應一支影片，而影片也是 Module 的內容載體。

---

# Module Categories

目前 JOTI 將 Module 分為六大類：

## 1. Tuning In 調頻

Purpose：

建立練習空間，調整身心狀態，正式開始 Practice。

通常包含：

* 調頻（Adi Mantra）
* 調頻（Adi Mantra + 保護咒）

---

## 2. Warm Up 熱身

Purpose：

喚醒身體、調整呼吸、準備進入主要練習。

可能包含：

* 呼吸熱身
* 貓牛式
* 脊椎暖身
* 關節活動
* 其他暖身動作

部分身體動作序列已包含完整熱身，因此可省略獨立熱身 Module。

---

## 3. Asana 身體序列動作 （Physical Kriya 身體奎亞）

Purpose：

透過身體姿勢、呼吸與節奏的結合，完成主要練習內容。

在 JOTI ABC 系統中，Asana 指的是以身體動作為主的 Module 類型；實際內容是一套 Physical Kriya，由多個 Asana 所組成。

例如：

* 清晨薩達那
* 心輪練習
* 消化系統練習
* 脊椎能量練習

---

## 4. Relaxation 放鬆休息

Purpose：

讓身體吸收前面練習所帶來的影響，恢復平衡。

通常包含：

* 大休息（Savasana）
* 引導放鬆

部分短時間 Practice 可省略。

---

## 5. Meditation 冥想

Purpose：

透過呼吸、唱誦、專注或靜心，整合整堂 Practice。

可能包含：

* 呼吸冥想
* 唱誦冥想
* 靜心冥想

此類 Module 對應昆達里尼瑜伽中的 Meditation Kriya。

---

## 6. Ending 結尾

Purpose：

完成整堂 Practice，回到日常生活。

通常包含：

* Long Time Sun
* Sat Nam

---

# Practice Composition

Module 在 Practice 中是否為必要、Practice 的結構分類（Full Practice / Meditation Practice），以及組課驗證規則（例如 Asana 數量限制），統一定義於 `practice-library.md` 的 Practice Structure 章節，此處不重複列出。

---

# Module Attributes

每個 Module 建議具備以下資訊：

* ID
* Title（名稱）
* Chinese Title 

* Type
* Category（分類）
* Subcategory（選填；部分 Module 沒有 Subcategory 屬於正常情況，非文件缺漏）

* Difficulty（適合程度）
* Duration（時間）

* Description（簡介）
* Learning Outcomes
* Prerequisites

* Sources

* Video Reference（對應影片）

* Transcript

* Resources

* Tags（標籤）

---

# Relationship

Foundation 建立基本能力。

Module 是組成 Practice 的基本元件。

Practice 由多個 Module 所組成。

每個 Module 對應一支影片，學員依照 Module 順序觀看與完成整堂 Practice。
