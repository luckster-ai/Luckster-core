# Tuning In (Standard)

## Description

本 Module 包含黃金鏈接與保護咒，作為正式練習開始前的調頻程序，協助學員安定心念、連結傳承，並建立安全而專注的練習空間。

---

## Learning Outcomes

完成本 Module 後，學員應能：

- 正確誦唱黃金鏈接與保護咒。
- 理解調頻在 ABC 昆達里尼瑜伽中的目的。
- 以穩定而專注的狀態開始後續 Practice。

- FD003 Body Locks（建議）
