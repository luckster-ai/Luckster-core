# Guided Savasana Relaxation

## Description

本 Module 採用攤屍式（Savasana）進行深度放鬆，透過溫和的口語引導，協助身體釋放緊張、平衡神經系統，並整合前一階段奎亞練習所帶來的效益。

---

## Learning Outcomes

完成本 Module 後，學員將有機會：

- 體驗深度的身心放鬆。
- 提升對身體與呼吸的覺察。
- 感受練習後的平靜與整合。
