# Kirtan Kriya

## Description

Kirtan Kriya 是一項結合唱誦、手印與專注力的經典冥想。透過重複神聖音節與配合手指動作，練習者得以安定心念、提升覺察，並培養內在的平靜與清晰。

---

## Learning Outcomes

完成本 Module 後，學員將有機會：

- 體驗唱誦與手印結合所帶來的專注狀態。
- 增進內在平靜與心智清晰度。
- 建立持續進行冥想練習的信心。
